# HOSE SURVIVORS

A humorous 2D bullet-heaven roguelite set in the Cinematic Universe of Jon Hose.
Survive ten minutes in The Dry Wastelands, evolve the Holy Hose, and stop the Great Drying.

**Status:** v0.1.0 — Phase 1 vertical slice (playable start to finish, placeholder art and audio).

## Run the game

1. Install [Godot 4.6](https://godotengine.org/download) (standard build; 4.4+ should also work).
2. Open the Godot project manager → **Import** → select this folder's `project.godot`.
3. Press **F5**.

Or from a terminal in the project folder (the first command imports assets once):

```bash
godot --headless --import
```

```bash
godot
```

### Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Move | WASD / arrow keys | Left stick / d-pad |
| Pause | Esc / P | Start |
| Menus | Arrows + Enter, or mouse | Stick/d-pad + A |

Weapons fire on their own. Collect the blue droplets. Stay hydrated.

## Tests

```bash
godot --headless --fixed-fps 60 res://tests/run_tests.tscn
```

```bash
godot --headless --fixed-fps 60 res://tests/sim_run.tscn -- --god
```

```bash
godot --headless --fixed-fps 60 res://tests/sim_run.tscn -- --bot=idle --then-restart
```

The first runs the unit tests; the second has a bot play a complete 10-minute run
through the boss to the victory screen (about a minute of wall time); the third
checks the defeat screen and restarting. See `ARCHITECTURE.md` §7.

## Regenerating placeholder assets (optional)

Requires Python 3 with Pillow.

```bash
python3 tools/gen_art.py
```

```bash
python3 tools/gen_audio.py
```
